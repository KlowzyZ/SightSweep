# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| Earlier builds | No |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. If it is unavailable, open a minimal public issue requesting a private contact channel without including sensitive details.

Do not publish passwords, authorization headers, credential-bearing URLs, camera streams, customer data, public IP targets, full private-network inventories, or exploit details in an issue.

Include the SightSweep version, Windows version, concise impact, safe reproduction steps, and whether credentials or private network data could be involved.

## Scope

Security reports about SightSweep are welcome. Requests to break into, bypass, reset, exploit, or guess credentials for third-party devices are out of scope.
